Below is a **detailed, implementation-grade specification sheet** for a **provider-agnostic Resource-Aware AI SDK** (NPM + PyPI). It is written as a product + engineering spec that can be handed directly to a team to build and publish.

---

# 1) Product Definition

### Name

* `resource-aware-ai` (NPM)
* `resource_aware_ai` (PyPI)

### Category

Infrastructure SDK / Middleware

### Purpose

Convert any LLM API call into a **resource-aware execution** that:

* estimates energy usage (kWh)
* estimates water usage (ml)
* optionally optimizes execution
* returns **metrics + human-readable sustainability footnote**

---

# 2) Functional Requirements

## 2.1 Core Capabilities

| Capability           | Description                                                        |
| -------------------- | ------------------------------------------------------------------ |
| Provider abstraction | Works with OpenAI, Anthropic, Gemini, local models, or custom APIs |
| Resource estimation  | Estimates kWh and water usage per request                          |
| Baseline comparison  | Computes savings vs worst-case baseline                            |
| Footnote generation  | Human-readable sustainability output                               |
| Mode selection       | performance / balanced / water_saver                               |
| Extensibility        | Custom providers + custom estimation models                        |

---

## 2.2 Non-Goals (Explicit)

* No direct hardware telemetry dependency (optional later)
* No requirement for proprietary infrastructure
* No enforced routing (SDK only, not orchestrator)

---

# 4) Public API Specification

## 4.1 Core Method

### Node + Python (Unified Concept)

```ts
chat({
  model: string,
  provider: string,
  messages: Message[],
  mode?: "performance" | "balanced" | "water_saver",
  constraints?: {
    max_water_ml?: number,
    max_kwh?: number
  }
}) → Response
```

---

## 4.2 Message Schema

```json
{
  "role": "user | system | assistant",
  "content": "string"
}
```

---

## 4.3 Response Schema

```json
{
  "output": "string",
  "metrics": {
    "energy_kwh": number,
    "water_ml": number,
    "baseline_water_ml": number,
    "water_saved_percent": number
  },
  "footnote": "string"
}
```

---

# 5) Core Algorithms

## 5.1 Token Estimation

### Default Heuristic

```text
tokens ≈ characters / 4
```

---

## 5.2 Energy Model

```text
kWh = (tokens / 1000) × model_factor
```

### Model Factors

| Model Class                | Factor (kWh / 1k tokens) |
| -------------------------- | ------------------------ |
| small (≤7B)                | 0.0004                   |
| medium (8B–30B)            | 0.0012                   |
| large (≥70B / GPT-4 class) | 0.0025                   |

---

## 5.3 Water Model

```text
water_ml = kWh × region_factor
```

### Region Factor

| Cooling Type | ml per kWh |
| ------------ | ---------- |
| Air cooled   | 0–500      |
| Hybrid       | 500–2000   |
| Evaporative  | 2000–5000  |

---

## 5.4 Baseline Model

```text
baseline = large_model × worst_region_factor
```

---

## 5.5 Savings Calculation

```text
water_saved_percent =
  (baseline - actual) / baseline × 100
```

---

# 6) Modes Behavior

| Mode        | Behavior                              |
| ----------- | ------------------------------------- |
| performance | no optimization                       |
| balanced    | moderate model efficiency             |
| water_saver | reduce model size, encourage batching |

# 9) Caching Layer (Optional but Critical)

## 9.1 Behavior

* Hash input messages
* Return cached result if identical

## 9.2 Impact

* eliminates recomputation
* reduces water usage to ~0 for repeated queries

# 20) Minimal Usage Example (Final Validation)

### Node

```javascript
const AI = require("resource-aware-ai");

const ai = new AI();

const res = await ai.chat({
  model: "gpt-4o",
  provider: "openai",
  messages: [{ role: "user", content: "Explain AI" }]
});

console.log(res.output);
console.log(res.footnote);
```

---

### Python

```python
from resource_aware_ai import ResourceAwareAI

ai = ResourceAwareAI()

res = ai.chat(
    model="gpt-4o",
    provider="openai",
    messages=[{"role": "user", "content": "Explain AI"}]
)

print(res["output"])
print(res["footnote"])
```
